# City map assets

Gli SVG in questa cartella sono rappresentazioni editoriali semplificate generate da dati © OpenStreetMap contributors, disponibili secondo Open Database License (ODbL): https://www.openstreetmap.org/copyright.

Le geometrie sono state ridotte alle arterie principali, ai corsi d’acqua, alle coste e ai parchi utili a rendere riconoscibile il centro urbano. Gli asset non contengono tile, etichette, marker o richieste remote a runtime.
